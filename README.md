
# Markov Text Generator

This Java-based project implements a **Markov Chain** algorithm to generate autonomous text. It was developed as part of my programming curriculum at **École Polytechnique**.

## Features
*   **Data Processing**: Reads and analyzes large text files (e.g., *Madame Bovary*).
*   **Stochastic Generation**: Uses probabilities to predict and generate the next word in a sequence.
*   **Customizable**: Users can adjust the generation parameters for different linguistic results.
